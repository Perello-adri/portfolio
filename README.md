# Portfolio de Adrian

¡Bienvenido/a al repositorio oficial de mi portfolio personal!

## Descripción
Este repositorio público contiene la estructura inicial de mi portfolio web. Ha sido creado como parte del módulo de Desarrollo Web para mostrar mis proyectos, mi entorno de trabajo y mi evolución en la programación.

## Sobre mí
* **Nombre:** Adrian
* **Usuario de GitHub:** [Perello-adri](https://github.com/Perello-adri)
* **Intereses:** Desarrollo web y jugar a videojuegos.

## Estructura del Proyecto
* `index.html`: Portada del portfolio con mi presentación personal y lista de proyectos.
* `entorno.html`: Explicación detallada sobre el funcionamiento del modelo cliente-servidor (viaje de una URL), las herramientas que utilizo y la estructura de carpetas.
* `README.md`: Documento principal de presentación del repositorio.
* `img/`: Carpeta para alojar recursos visuales e imágenes.

## Tecnologías Utilizadas
* **HTML5**
* **Git & GitHub**
* **Visual Studio Code** (con extensión **Live Server**)
