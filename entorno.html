El viaje de una URL (Cliente-Servidor)

Cuando escribes una URL en la barra del navegador y pulsas Enter, ocurre el siguiente proceso:

  1. Resolución DNS: El navegador solicita a un servidor DNS que traduzca el nombre de dominio en la dirección IP del servidor donde está alojada la web.
  2. Petición HTTP/HTTPS: El cliente (navegador) envía una solicitud de conexión al servidor utilizando esa IP.
  3. Procesamiento en el Servidor: El servidor procesa la petición, busca los archivos requeridos y prepara la respuesta.
  4. Respuesta y Renderizado: El servidor devuelve los archivos HTML, CSS e imágenes, y el navegador los interpreta para mostrar la página web en pantalla.

Herramientas de Desarrollo y por qué las uso

  • VS Code (Visual Studio Code): Es mi editor de código principal porque es rápido, intuitivo y permite organizar mis proyectos con facilidad.
  • Extensiones de VS Code: Utilizo extensiones para mejorar mi productividad, formatear código y detectar errores rápidamente.
  • Live Server: Uso esta extensión porque abre un servidor local que refresca la página automáticamente cada vez que guardo un cambio, ahorrándome tiempo.
  • Git: Lo utilizo como sistema de control de versiones para guardar el historial de cambios de mi proyecto de forma ordenada y sin perder información.
  • GitHub: Lo empleo para almacenar mis repositorios en la nube, publicar mi portfolio y compartir mi código de manera pública de forma profesional.
